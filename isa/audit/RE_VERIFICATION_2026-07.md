# 🔁 ISA 문제은행 전수 재검증 보고서 (Re-Verification, 2026-07)

전체 500문항을 대상으로 한 2차 전수 재검증. **verification 항목 중심**으로 (1) 자기일관성
스캔, (2) 반복 핵심 사실 웹 검증, (3) 확정 항목 플래그 해제, (4) 잔여 항목 분류를 수행했다.

## 1. 자기일관성 스캔 (answer ↔ calculation)

계산형 106개 문항의 정답 요약 금액이 계산과정·해설과 일치하는지 프로그램으로 대조했다.

- **검출된 실질 결함 2건 → 수정 완료**
  - `ISA-B10-015`: 정답 요약에 자기수정 미완 문구("…=39,600원? 재확인 —")가 잔존 →
    정답을 **"0원"**(과세순이익 400만 = 서민형 한도 400만)으로 정정.
  - `ISA-B10-022`: 동일 유형("…=9,900원? 재확인 —") → 정답을 **"99,000원"**(초과분 100만×9.9%)으로 정정.
- **표현 정리 2건**: `ISA-B02-047`, `ISA-B06-028`의 수사적 "9,900원이 아니라 …" 표현을
  정답에서 제거하고 정확 금액만 기재(자릿수 오류 경고는 `common_misconceptions`에 유지).
- 나머지 11건은 오탐(정답은 `원`, 계산은 `만원` 표기 차이)으로 값은 정확함을 확인.
- 재스캔 결과 정답 내 미완 자기수정 문구(`재확인`) **0건**.

| 사적연금 종합과세 기준 **연 1,500만원**(초과 시 전체 연금소득에 종합과세 6.6~49.5% 또는 16.5% 분리과세 선택) | ✅ 확인 | 소득세법 |
| 연금소득세율 **5.5%(55~70세)/4.4%(70~80세)/3.3%(80세~)** | ✅ 확인 | 소득세법 |

## 3. 확정에 따른 플래그 해제 (verification_needed → false, 29건)

위 웹 확인으로 **유일한 불확실성이 해소된** 문항 29건의 `verification_needed`를 false로
전환하고, `verification_note`에 확정 근거(출처·수치)를 기재했다.

- 연금전환 60일·10%·300만·1,200만: B01-031·032, B02-033, B04-043·044, B05-033, B08-037·038, B10-033
- 세액공제 한도·율(600/900, 16.5/13.2%): B05-001·002·019·024·026·046, B10-012
- 연금소득세·종합과세 기준(5.5/4.4/3.3%, 1,500만): B05-003·004·013·025·028·045·049, B10-008·017
- IRP 위험자산 70%: B03-040, B05-011
- 서민형 소득요건: B04-025, B08-001

**결과: `verification_needed` 325 → 296 (65.0% → 59.2%).**

## 5-2. 집중 재검증: 국내주식 '손실' 손익통산 (조건부 → 확정)

기존에 조건부(해석 A/B 병기)로 남겨 두었던 최대 쟁점을 집중 재검증하여 규칙을 확정했다.

- **확정 규칙** (복수 증권사 실무 안내로 확인, 중개형 ISA의 대표 장점으로 명시됨):
  - 국내 상장주식 **직접투자 매매손실 → 배당·이자 등 과세소득과 손익통산 가능** (과세소득 감소).
  - 국내주식 매매차익은 비과세라 통산 이익이 없어 **실질적으로 '손실'만 유효 반영**.
  - **국내주식형 펀드·ETF 손실 → 통산 불가** (매매차익 비과세로 과표기준가 미반영).
- **정정 문항 5건**:
  - `ISA-B04-001`, `ISA-B10-004`(계산): 정답을 조건부 → **0원**(직접주식 손실 통산)으로 확정, 펀드·ETF 대조값(247,500/346,500원) 병기.
  - `ISA-B03-022`, `ISA-B04-023`(세제): 확정 규칙(직접주식 통산 가능 / 펀드·ETF 불가)으로 정정, 상계 순서는 총 세액 불변임을 명시.
  - `ISA-B10-029`(조건부 쟁점 목록): 국내주식 손실 통산을 '확정'으로 이동.
- 4건(`B03-022`·`B04-001`·`B04-023`·`B10-004`) `verification_needed=false` 전환.
- **결과: verification 296 → 292 (59.2% → 58.4%).**
- 근거 한계: 규칙은 복수 증권사 실무 자료로 확인. 최종 아카이브 확정을 위해 국세청 유권해석·조특법 시행령 원문 대조를 권장한다.

## 5-3. 확정 작업: 높음·중간 확정가능성 영역 (292 → 268)

verification 6대 분류(운영 101·수치 86·시행령 31·유권해석 28·상속 24·외국 22, 데모
`audit/verification_demo.html`) 중 **확정 가능성이 높음·중간인 영역**을 권위 출처로
집중 검증하여 확정했다. 반복 의존 핵심 사실 4건을 국가법령정보센터·상증세법으로 확인했다.

| 확정 사실 | 내용 | 출처 |
|---|---|---|
| **조특법 시행령 제93조의4** | ISA 위임 시행령 조문 번호. 가입요건 제3항, 부득이한 사유 제12항. (기존 추정 제93조의18은 오류) | 국가법령정보센터 |

## 6. 결론

- **정답 오류(계산·논리)**: 2건 검출·수정, 재스캔 클린.
- **핵심 반복 사실**: 7개 범주 권위 출처로 확정, 관련 29문항 플래그 해제.
- **국내주식 손실 손익통산**: 집중 재검증으로 규칙 확정(직접주식 통산 가능 / 펀드·ETF 불가), 5문항 정정·4문항 해제.
- **높음·중간 확정 작업**: 시행령 제93조의4·부득이한 사유 열거·상속/증여세 수치·미성년 요건을
  권위 출처로 확정, **24문항 플래그 해제 + 11문항 정밀화 + 조문 오류 3건 정정**.
- **잔여 268건**: 외국(미국) 세법·증권사 운영기준·개별 유권해석 의존으로 **계속 조건부
  유지**(정직성 우선). 성격상 웹 일반검색으로 단정할 수 없는 항목이다.
- 종합 품질 점수 상향: **89 → 90/100** (확정 해제분 누적 반영, 잔여 원문 확정 시 추가 상향).

> ⚠️ 잔여 268건은 실무 적용·서비스 투입 전 원문(국가법령정보센터·국세청·미국 세법 등)
